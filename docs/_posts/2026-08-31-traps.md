Traps are a hazard which can be encountered either on a square, or on a treasure
chest. There are 18 types of trap, with various effects.

### Encountering a trap

Dungeon map square type `02` (see [dungeon map format](../data/dungeon-format.html))
indicates the presence of a trap, which triggers upon entering the square. The
subtype byte determines which of the 18 trap types it uses. Some (marked
"Party") in the table strike all six party members, while others (marked "Four")
affect only the front four members and spare the back row.

Dungeon map square type `04` indicates a treasure chest. If the first byte of
the item list is `0xfe`, the chest is trapped, and the next byte is the type ID.
It triggers when the chest is opened, and affects only the individual who opened
it.

### Disarming the trap

Each trap has a level, which determines how hard it is to spot. This level
ranges from 3 to 8.

When the party enters a trap square, if the party contains at least one Thief
whose character level is equal or higher to the trap level, the trap is
automatically found and disarmed.

A chest trap can be disarmed by the hero who opens it, even if they are not a
thief, but thieves have an advantage at this task. The first number is the level
required for a non-Thief, while the number in parentheses is the level required
by a Thief.

### Trap effects

Each trap has an attack value from 3 to 15. Any target with a WC (armour) value
higher than this ignores the trap's effect (can parry). Otherwise, they take the
trap's effect.

Each trap deals a random amount of damage in a certain range.

Additionally, some traps have inflict a status effect: either Poisened, or
Blinded. There is a random 50/256 chance (approximately 20%) of being afflicted
with the status effect.

### Notes

- Trap `0a` is mistranslated; according to the German, it should be
  "Spears shoot up from the floor."
- Some traps do not appear:
  - Traps `00` (banshee), `07` (cloud of poisen), and `0a` (trapdoor) appear
    only in DoA1.
  - Trap `04` (poisened arrows) appears only in DoA2.
  - Trap `09` (trapdoor) is not used in either game.
- Some traps change between DoA1 and DoA2:
  - Trap `00` (banshee) becomes much more deadly: attack and level 32, meaning
    it hits everyone and can only be disarmed by legendary thief NPC Rahven;
    and damage increases from 40-60 to 60-90. However, this trap doesn't appear
    in any level. The DoA2 version has been omitted from the table on this page.
  - Trap `0b` (falling stones) becomes easier to dodge: attack reduced from 10
    to 4 (as noted in the table).
- Some traps have a more deadly version with the same description text:
  - Poisened arrows: Type `04` hits only the front two rows, while `05` hits the
    entire party, deals twice as much damage, and is harder to spot and resist.
    Type `04` only appears in DoA2.
  - Cloud of poisen: Type `06` hits only the front four. Type `07` hits the
    entire party, and is harder to spot and resist, but does the same damage.
- Technically, chest traps have a level between 3 and 5. The character subtracts
  2 from their effective character level (minimum 0), and a Thief then adds +4
  to their level. The result is that the starting Thief character, and any
  character of level 7 or higher, can safely open all chests.

### Data

8 bytes per trap

- 00: Hit
- 01: Level
- 02: Target
- 03: Text ID
- 04: Damage (base)
- 05: Damage (variable)
- 06: Status effect
  - 80: GI - Poisen
  - 40: ST - Stone
  - 20: VR - ???
  - 10: BL - Blind
- 07: Padding
